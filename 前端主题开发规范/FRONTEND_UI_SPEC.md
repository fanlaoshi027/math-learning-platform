# 前端 UI 设计规范

版本：V1.0

## 1. 设计目标

主题可以完全重新设计视觉，但必须保持产品结构和业务行为不变。

关键词：

- 简洁
- 现代
- 教育感
- 清晰
- 手机优先
- 微信端友好

参考 UI 可以改变视觉，不得照搬参考 HTML 的业务逻辑。

## 2. 当前视觉方向

现有主题方向：

- 深海蓝作为主要品牌色
- 活力橙作为 CTA/强调色
- 浅灰或白色背景
- 大圆角卡片
- 轻量阴影
- 清晰的层级排版

新主题可以改变颜色和视觉，但建议保持良好的教育产品识别度。

## 3. 课程卡片

建议组成：

```text
┌────────────────────┐
│                    │
│      课程封面       │
│                    │
├────────────────────┤
│ 七年级 · 专题课程  │
│ 课程名称            │
│                    │
│ [进入学习 →]        │
└────────────────────┘
```

封面优先使用插件返回的 `cover`。

没有封面时使用主题自己的占位设计：色块、数学元素、课程名称等均可。

不要出现破图、空白大区域或默认浏览器图片图标。

## 4. 学习中心卡片

学习中心必须突出进度。

建议：

- 课程封面
- 课程名称
- 已完成 / 总课时
- 百分比
- 进度条
- 继续学习按钮

不要增加错题本、笔记本、教师笔记等未定义产品功能。

## 5. 播放器

播放器是核心学习场景，应尽量减少视觉干扰。

建议：

- 视频区域突出
- 控制栏清晰
- 控件间距适合触摸
- 倍速容易找到
- 进度条容易拖动
- 当前课时清晰
- 章节目录层级清楚

## 6. 章节目录

章节采用折叠设计：

`▾` = 展开
`▸` = 收起

课程章节较多时，目录必须使用独立滚动区域，不允许整个页面被无限撑长。

当前课时、已完成课时、试看课时、锁定课时应有明显但克制的视觉区别。

## 7. Header

桌面端：

- Logo/品牌
- 首页
- 课程中心
- 登录用户显示学习中心
- 登录/用户入口

游客不显示学习中心。

移动端：

- 不允许导航把页面撑宽
- 可以横向滚动导航，或采用合适的移动菜单
- 触控目标足够大
- 不显示横向滚动条

## 8. 按钮

主操作使用高识别度 CTA。

按钮文字应该直接描述动作：

- 开始学习
- 继续学习
- 进入课程

避免使用含义模糊的“点击这里”等文字。

## 9. 状态设计

必须考虑：

- 空课程
- 无封面
- 无视频
- 未授权
- 试看
- 已完成
- 加载中
- 登录要求
- 错误状态

## 10. 响应式

至少验证：

- 360px
- 375px
- 390px
- 430px
- 平板
- 1366px 以上桌面

所有页面不得产生意外横向滚动。

## 11. 性能

主题尽量：

- 少加载 JS
- 少加载第三方库
- 图片使用 lazy loading
- CSS 集中管理
- 不重复加载播放器资源
- 不在主题中重复实现插件业务功能
