# 前端页面开发规范

版本：V1.0

## 1. 产品页面结构

最终前台只保留四类核心页面：

1. 首页
2. 课程中心
3. 学习中心
4. 播放页面

不需要独立课程详情页，也不需要专题详情页。

## 2. 游客流程

```text
首页
 ↓
课程中心
 ↓
选择课程
 ↓
播放页面
```

游客可以浏览课程中心中的课程。

播放器由插件根据课时权限决定哪些内容可以试看。

## 3. 登录学员流程

```text
首页
 ├─→ 课程中心 → 播放页面
 └─→ 学习中心 → 授权课程 + 学习进度 → 播放页面
```

学习中心不是全部课程列表，只显示当前用户已经获得授权的课程。

## 4. 首页

主题负责：

- Hero
- 品牌信息
- 课程入口
- 教师介绍
- CTA
- 页脚

首页不得自行查询 Tutor LMS 数据库。

## 5. 课程中心

必须能够展示全部公开课程，并支持：

- 课程封面
- 无封面占位
- 课程名称
- 年级
- 课程类型
- 进入学习按钮
- 类型筛选
- 年级筛选

课程卡片点击后直接进入：

`/learning/?course_id={ID}`

不要增加课程详情页面。

## 6. 学习中心

仅登录用户使用。

建议页面结构：

```text
我的课程
已授权课程与学习进度

[课程卡片]
封面
课程名称
学习进度  8 / 20    40%
████████░░
[继续学习 →]
```

无授权课程时显示友好的空状态。

## 7. 播放页面

核心区域：

```text
┌─────────────────────────────┐
│                             │
│          视频播放器          │
│                             │
└─────────────────────────────┘

课程名称
当前课时

右侧/下方：
章节
  ▾ 第一章
      ○ 课时 1
      ✓ 课时 2
  ▸ 第二章
```

章节很多时，章节区域必须独立滚动。

章节可以点击三角形展开/收起。

## 8. 播放器控制栏

当前产品需要：

- 播放/暂停
- 进度条
- 当前时间/总时长
- 倍速
- 快退 10 秒
- 快进 10 秒
- 音量
- 全屏
- 横屏能力（移动端条件支持）
- 颜色/反色相关功能（由现有播放器提供）

主题只负责控制栏视觉，不重写播放器核心逻辑。

## 9. 移动端

重点兼容：

- iPhone Safari
- 微信内置浏览器
- Android 微信
- 常见 360px–430px 宽度

要求：

- 页面不得出现横向溢出
- Header 在窄屏保持稳定
- 课程卡片自适应
- 播放器宽度不超过视口
- 章节列表可以独立滚动
- 按钮触控区域足够大

## 10. 页面之间的职责

| 页面 | 游客 | 登录学员 |
|---|---|---|
| 首页 | ✓ | ✓ |
| 课程中心 | ✓ | ✓ |
| 学习中心 | × | ✓ |
| 播放页面 | 按试看权限 | 按授权权限 |

## 11. 课程详情页

明确禁止新增独立课程详情页。

旧课程详情 URL 仅作为兼容入口，最终应进入播放器。
