# Mosuan Board

> 面向数学教师的 PDF 电子黑板

Mosuan Board 是一个以数学教师课堂书写为核心的数字黑板应用。第一阶段以 macOS 为主要开发平台，同时从第一天起保持 Windows 与 Android 平板的可移植性。

## 产品定位

- 产品体验参考 Drawboard PDF 的简洁、专业与易用性。
- Xournal++ 仅作为技术研究与实现参考，不作为 UI/交互参考。
- PDF 是电子黑板，而不是普通 PDF 阅读器。
- PDF 原始内容保持不变，教师书写和数学图形位于独立的可编辑注释层。
- 书写数据从第一天起采用矢量/结构化数据，不以截图或位图作为核心数据。

## 核心能力

1. 低延迟、压力感应的自然书写。
2. 钢笔、荧光笔、橡皮、选择、撤销/重做。
3. 结构化数学图形：直线、箭头、多边形、三角形、圆、坐标系、函数图像等。
4. 对象选择、节点编辑、移动、缩放、旋转、镜像和精确属性调整。
5. 我的图库：保存并复用教师自己的矢量图形。
6. PDF、白板、黑板三种使用场景共享同一套标注引擎。
7. 护眼模式：选择性反转黑白背景，同时尽量保持彩色内容的色相与饱和度。
8. `.mosuan` 原生矢量教学文档格式。
9. 高质量打印以及 PDF + 笔记 / 仅原 PDF 两种打印方式。
10. 后续支持激光笔、课堂录制、Windows 与 Android 平板。

## 当前开发原则

- 先验证低延迟书写，再扩展复杂功能。
- 平台输入、业务模型、渲染器分层，避免 macOS API 渗透到核心模型。
- 不把所有内容都当作 Stroke；数学图形必须是结构化 GraphicObject。
- 高级功能隐藏在图库/更多菜单中，常用功能保持触手可及。
- 不为了功能数量牺牲课堂使用的稳定性和简单性。

## 开发阶段

### Phase 0 — 架构与低延迟验证

只做输入、采样、压力、平滑、实时渲染、橡皮和撤销/重做，先证明“写起来像真的笔”。

### Phase 1 — 基础电子黑板

加入 PDF、页面管理、选择、基础结构化图形、属性面板和保存。

### Phase 2 — 数学教师工具

加入图库、坐标系、函数图像、几何工具、常用笔槽和课堂工具。

### Phase 3 — 课堂增强

加入护眼模式、激光笔、讲课模式、打印优化和录制。

### Phase 4 — 跨平台

在保持核心数据模型和输入抽象不变的前提下扩展 Windows 与 Android 平板。
