# 墨算图库设计

## 目标

墨算图库不是简单的图片收藏夹，而是一个可直接拖入画布、继续编辑的**教学图例库**。

图库分为两层：

1. **墨算预设图库**：软件内置的高频数学教学图例。
2. **教师自建图库**：教师自己绘制并保存的常用图例，以及课程作者随课程提供的图库。

所有可编辑图例最终都转换为墨算自己的 `GraphicObject` / `Group` 数据，而不是只保存 PNG/JPG。这样拖入画布后可以移动、缩放、旋转、改色、改线宽，并继续书写。

## 图库分类

### 1. 基础几何

- 点、线段、射线、直线
- 平行线、垂线
- 角、直角、平角
- 三角形、等腰三角形、等边三角形
- 四边形、平行四边形、矩形、菱形、正方形
- 圆、弧、扇形
- 常见辅助线

### 2. 坐标与函数

- 标准直角坐标系
- 第一/第二/第三/第四象限坐标系
- 带网格坐标系
- 一次函数图像
- 反比例函数图像
- 二次函数图像
- 抛物线 + 对称轴 + 顶点
- 函数图像与坐标点组合

这些预设优先做成**参数化图例**，例如坐标轴范围、网格间距、函数系数可以继续编辑，而不是固定成图片。

### 3. 初高中常用模型

首批重点加入：

- 手拉手模型
- A 型 / X 型相似模型
- 等腰三角形辅助线模型
- 全等三角形常用摆放模型
- 角平分线模型
- 中线模型
- 垂径定理模型
- 圆周角/圆心角模型
- 二次函数常见图像模型
- 动点几何基础模型

## 教师自建图库

教师在画布中完成一个图例后，可以：

`选中对象 → 加入图库`

保存内容包括：

- 名称
- 分类
- 缩略图
- GraphicObject / Group 数据
- 原始坐标
- 默认线条颜色
- 默认线宽
- 创建时间
- 最近使用时间

推荐默认名称：

`手拉手模型 01`
`我的坐标系`
`二次函数模板`

## 课程图库

课程作者可以为课程附带专属图库，例如：

`八年级上册 · 全等三角形`

其中可以直接提供：

- 手拉手模型
- 全等模型
- 辅助线模板
- 常见坐标图
- 本课程专用示意图

课程图库与系统预设图库、教师个人图库分开管理，但在画布中统一使用。

## 拖入画布

图库采用侧边栏/浮层方式。

推荐交互：

`图库 → 长按/拖动 → 画布 → 松手`

对象落点后自动适配当前缩放比例，并保持图例内部比例。

也支持：

`点击图例 → 以默认大小插入画布中心`

## 编辑规则

拖入后的图例不是图片。

例如“手拉手模型”应由多个 GraphicObject 组成：

- 三角形边
- 顶点
- 辅助线
- 标记
- 文本

整体默认作为一个 `Group`，但可以：

- 整体移动
- 整体缩放
- 整体旋转
- 解除组合
- 单独修改其中对象
- 删除其中某条辅助线
- 在图例上继续手写

## 数据结构建议

新增：

```text
LibraryItem
├── id
├── name
├── category
├── source
│   ├── builtin
│   ├── teacher
│   └── course
├── thumbnail
├── payload
│   └── GraphicObject / Group[]
├── defaultScale
└── metadata
```

课程图库额外包含：

```text
courseID
courseVersion
```

但图库对象本身不绑定学生页面，也不参与课程版本迁移。

## 首期实现范围

Windows / macOS / iPadOS 共用图库核心数据模型。

首期先实现：

1. 系统预设图库
2. 教师“加入图库”
3. 个人图库删除/重命名
4. 点击插入
5. 拖动插入
6. 插入后继续编辑
7. Group 整体操作
8. 解除组合

暂不做：

- 云端图库同步
- 社区图库
- 在线商城
- 图片识别生成可编辑图例

## 产品原则

图库的核心不是“找图片”，而是：

> **把老师平时反复画的东西，变成可以一拖就用、拖出来还能继续改的教学组件。**

这会成为墨算区别于普通白板软件的重要能力之一。
