## 一、项目定位

这是“樊老师数学”在线课程平台，基于 WordPress + Tutor LMS Pro 构建。

核心原则：

1. **Tutor LMS Pro 4.0.4 作为底层 LMS 驱动。**
2. MathCourse 负责网站自己的课程业务、权限、视频、学习进度和前台体验，但不重新制造一套完整 LMS。
3. Tutor LMS 原生课程、Topic、Lesson 数据结构继续作为课程数据源。
4. 通过 `Tutor\Adapter` 隔离 Tutor LMS API，业务模块尽量不要直接调用 Tutor API。
5. 课程权限统一由 `Access_Service` 决定，避免出现多套授权规则。
6. 学习进度统一由 `Progress_Service` 管理。
7. 视频播放统一经过 `Course_Service` + `Video_Router`，未授权时不得向前端返回受保护 HLS 地址。
8. 前台保持极简，不增加错题本、笔记、教师笔记、本节知识点、下载讲义等非核心功能。
9. HLS 采用 m3u8 + ts 碎片，并通过服务端签名网关隐藏真实视频源。
10. 每次代码修改必须写入 Git，并同步更新本进度文件。


## 6. Video Router / HLS 网关

文件：

`wp/wp-content/plugins/math-course/includes/Video/class-video-router.php`

已完成：

- `/math-video/{lesson}/{expires}/{signature}/` 路由。
- HMAC-SHA256 签名。
- 默认短期 Token 有效期 600 秒。
- 播放列表请求前再次检查观看权限。
- `.ts` / `.m4s` / `.aac` 等媒体请求继续检查签名和权限。
- m3u8 返回时将源文件引用改写成受保护的 MathCourse 地址。
- 对 HLS 子 playlist 继续重写 URI，避免第二级 m3u8 暴露真实 Origin。
- 支持将浏览器 Range 请求转发到源站，并处理 206 / Content-Range。
- 浏览器端不直接得到真实 HLS Origin。
- 对跨域/非法媒体来源进行限制。
- 服务端从真实 HLS 源读取媒体后返回。

本轮新增：

- `rewrite_playlist()` 独立处理一级及多级 m3u8。
- `serve_media()` 发现 `.m3u8` 时再次执行重写，而不是把真实子播放列表原样返回。
- 媒体请求读取 `HTTP_RANGE` 并转发给源站。
- 源站返回 206 时向客户端保留 `Content-Range`。

仍需重点检查：

- EXT-X-MAP / fMP4 初始化片段。
- EXT-X-KEY 加密播放列表中的 URI 是否需要专门代理。
- URI 中特殊字符、空格和 query string。
- 大文件内存占用。
- CDN/缓存策略。
- Safari / iPhone 播放兼容性。
- 长视频并发情况下 PHP 网关性能。

**这些属于下一阶段重点，不要在没有实际验证前宣称视频防盗链已经完全达到生产级。**

# 七、已知风险

## 1. Video Router PHP 代理性能

当前媒体内容由 WordPress PHP 读取后再输出，因此大视频并发可能产生较高 PHP / 内存 / 带宽压力。

后续需要根据服务器实际环境评估：

- Nginx internal redirect。
- X-Accel-Redirect。
- CDN。
- 阿里云 OSS / CDN。
- 更轻量的签名网关。

在没有实际服务器测试前，不要假设当前 PHP 代理适合大规模并发。

## 2. HLS 加密

《网站开发备忘录》要求后续评估 AES 加密，但目前不能为了“看起来安全”直接加入复杂加密。

应该先把：

```text
权限
→ Token
→ Origin 隐藏
→ Playlist 重写
→ Media 鉴权
```

做稳定，再评估 AES-128 / KEY URI 代理。

## 3. Tutor LMS API

Tutor LMS 4.0.4 是当前开发基准。

任何不确定的 Tutor API、Hook、Model、Service 都必须核对实际源码或官方文档，不允许凭记忆猜测。
