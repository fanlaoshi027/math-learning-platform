# 网站开发进度记录目录

项目：`fanlaoshi027/math-learning-platform`
分支：`main`

本目录用于保存项目开发状态和历史开发记录。为避免单个 Markdown 文件过大，采用“当前状态 + 分卷历史”的方式。

## 文件规则

- `00-项目状态.md`：始终保持较小，只记录当前真实状态、当前任务、待办和最近 Commit。每次开发都更新。
- `01-开发记录.md`、`02-开发记录.md`、`03-开发记录.md`……：按时间顺序保存历史开发记录。
- 单个开发记录文件达到约 **20～30 KB** 时，不再继续追加，自动创建下一卷。
- 新卷从 `02-开发记录.md`、`03-开发记录.md` 依次递增。
- 不删除历史分卷，不覆盖旧记录。

## AI 接班读取顺序

正常继续开发时只需要：

1. `main/wp/wp-content/网站开发接班提示词.md`
2. `main/wp/wp-content/网站开发备忘录.md`
3. `main/wp/wp-content/网站开发进度/00-项目状态.md`
4. 当前编号最大的 `*-开发记录.md`
5. Git `main` 当前代码

只有追查历史设计原因时，才读取更早的分卷。

## 当前分卷

- `01-开发记录.md`：第一卷历史记录及迁移前的核心开发状态
- `02-开发记录.md`：前台 UI 第一阶段历史记录
- `03-开发记录.md`：当前前台重设计及课程详情/学习页整理记录
- 后续达到容量阈值后创建 `04-开发记录.md`

## 记录要求

每次代码修改后必须记录：

- 日期
- Commit
- 修改文件
- 本次完成内容
- 修改原因
- 解决的问题
- 当前状态
- 测试情况
- 已知风险
- 下一步

`00-项目状态.md` 与历史分卷共同构成项目接班资料；两者都必须保持与 Git 实际代码一致。
