## 项目

- GitHub：`fanlaoshi027/math-learning-platform`
- 分支：`main`
- 产品：樊老师数学在线课程平台
- 技术：WordPress + Tutor LMS Pro 4.0.4 + MathCourse + MathCourse Theme

## 当前架构

```text
WordPress
  ↓
Tutor LMS Pro 4.0.4
  ↓
Tutor\\Adapter
  ↓
Course_Service
  ├─ Access_Service
  ├─ Progress_Service
  └─ Video_Router
  ↓
课程中心 / 学习页 / Video Player
```

Tutor LMS 负责底层 Course / Topic / Lesson 数据；MathCourse 负责本项目的课程业务、权限、试看、视频、学习进度和前台体验。不要重新制造完整 LMS。

## 已完成核心工作

### Tutor / Course

- Tutor Adapter 已作为 Tutor API 统一适配层。
- Lesson → Course 归属统一通过 Adapter / Progress Service。
- Course Service 负责课程业务编排。
- Tutor Lesson Access 已统一走 Access Service。
- Preview 已统一走 Adapter。
- Course Service 创建 Video Router 时关闭 Hook 注册，避免重复注册 rewrite/template_redirect。

### 权限

- Access Service 作为最终课程/课时观看权限来源。
- 已授权用户可以观看授权课程。
- 未授权用户只能观看明确允许 Preview 的课时。
- 未授权状态不得向前端返回受保护 HLS 地址。
- Video Router 的 `get_protected_url()` 主动执行最终观看权限检查，实际 HLS 请求进入 `handle()` 后仍再次检查观看权限。
- 旧版 `mathcourse_complete` AJAX 已改为统一调用 Progress Service，不能再绕过课程/课时权限和完成规则。

### Video / HLS

- 已建立 `/math-video/{lesson}/{expires}/{signature}/` 网关。
- HMAC-SHA256 短期签名，默认 600 秒。
- 一级和多级 m3u8 会重写资源 URI。
- `.ts` / `.m4s` / `.aac` 等媒体请求重新验证签名和权限。
- Range / 206 / Content-Range 已有基础支持。
- EXT-X-MAP / EXT-X-KEY / EXT-X-MEDIA 等 URI 已纳入重写处理。
- 子 playlist URI 会按照声明它的 playlist 的路径解析。
- `get_protected_url()` 已增加最终 `can_watch()` 校验。

**尚未经过真实生产环境验证，不得宣称 HLS 防盗链已经完全生产级。**

### Progress / Player

- Progress Service 负责课时完成和课程完成百分比。
- 完成状态保存为用户 Meta：`mc_completed_lessons`。
- Lesson → Course 验证集中在 Progress Service。
- 播放到几分几秒与“课时完成”分开。
- 精确播放断点目前使用浏览器 localStorage，避免高频请求服务器。
- Player 在播放接近结尾且检测到真实播放后提交课时完成。
- 已修复 Player 的 `ended` 事件直接提交完成的问题：直接拖动/seek 到视频结尾不会立即把课时标记为完成，必须在最近一次 seek 后累计至少约 1.2 秒有效播放。
- Legacy `Tutor\\Complete` AJAX 已不再直接写学习表或信任客户端 `course_id`，统一委托 Progress Service。
