## 当前前台设计方向

前台正在全面重设计，课程只有两大类：

1. **专题课**：重点专题、系统突破。
2. **教辅配套**：跟着教辅、逐题讲解。

视觉坚持个人轻量网站：深海蓝 + 活力橙、白色卡片、大圆角、轻阴影、手机优先。不做商城化，不增加笔记、错题本、社区、讲义下载等非核心功能。

```text
 ├─ 当前课时
 ├─ 上一课 / 下一课
 └─ 课程目录
```

## 核心架构

- Tutor Adapter 统一 Tutor 数据访问。
- Course Service 负责课程业务编排。
- Access Service 负责课程/课时观看权限。
- Progress Service 负责课时完成与课程进度。
- HLS Video Router 负责短时签名、m3u8 重写及媒体请求权限验证。
- Player 使用 localStorage 保存播放断点，避免高频服务器请求。
- 课时完成通过统一 Progress AJAX 写入。
- HLS 原始地址不直接输出给前台。
- Access Service 对同一请求中的用户+课程授权查询使用轻量内存缓存。
- 后台课程编辑器已统一到 `_mathcourse_video_id`、`_mathcourse_hls_url`、`_mathcourse_page_number` 等标准课时 Meta，并兼容旧字段。
- 课程详情只负责课程目录；可访问课时统一进入“学习课程”页面，播放器只在学习页承担播放职责。
- 主题会在 `init` 阶段确保“学习课程” Page 存在，并自动绑定 `page-learning.php`，避免新测试站因数据库缺少该页面而出现 404。

## HLS 测试标准

测试阶段也以 HLS 流媒体为准，不围绕 MP4 开发测试功能。MP4 fallback 仅保留兼容能力。

正式测试需要验证：主/子 m3u8、ts/m4s、EXT-X-KEY、EXT-X-MAP、Range/拖动、签名过期、权限失效，以及 PC / Safari / iPhone / Android。
