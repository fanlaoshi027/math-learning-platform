## 2026-08-30 · 前台 UI 全新设计 · 第一阶段

### 设计目标

用户确认前台完全重新设计，并明确网站只有两大课程类型：

1. **专题课**：围绕数学专题进行系统突破。
2. **教辅配套视频课**：围绕教辅/教材按章节逐题讲解。

核心原则继续保持：个人轻量网站、页面轻快、功能少而清晰、不做商城化 LMS、不增加笔记/错题/社区/下载讲义等非核心模块。

### 信息架构

```text
首页
├─ 品牌 Hero
├─ 专题课入口
├─ 教辅配套入口
└─ 课程库

课程中心
├─ 全部
├─ 专题课
├─ 教辅配套
└─ 年级筛选

课程详情
├─ 课程标题
├─ 学习进度
├─ 继续学习
└─ 课程目录

我的学习
├─ 已授权课程
└─ 学习进度 / 继续学习

学习页
├─ HLS 视频
├─ 当前课时
├─ 上一课 / 下一课
└─ 课程目录
```

### 本轮实际代码修改

#### 1. `header.php`

重新设计网站顶部导航：

- 去掉搜索框。当前课程数量不大，不需要为了搜索引入额外视觉噪音和功能复杂度。
- 去掉注册按钮，保留 WordPress 登录入口；账号体系由现有系统处理。
- 导航统一为：首页 / 专题课 / 教辅配套 / 我的学习。
- 登录用户显示“我的学习”。
- 品牌标识由数学符号改为简洁的“樊”字方形标记，更贴合个人教师品牌。
- 当前页面导航增加 `is-active` 状态。

Commit：`f5aaddb2e3c0c35fc1ba84ba24900dd6bac57b4b`

#### 2. `front-page.php`

首页完全重新组织：

- 新 Hero：`把数学学明白，一步一步来。`
- 明确说明专题课与教辅配套视频课的区别。
- 增加两个大入口卡片：专题课 / 教辅配套。
- 保留课程库 shortcode，不改变现有课程查询、权限和数据结构。

#### 3. `assets/css/reference-ui.css`

整个前台视觉系统重新设计：

- 深海蓝 `#0d2942` 作为品牌主色。
- 蓝色 `#1769e0` 作为操作色。

- 统一按钮、导航、课程卡片、课程目录、学习中心和学习页的视觉语言。
- PC 使用三列课程卡片；中等屏幕两列；手机单列。
- 手机端隐藏桌面导航，保持顶部极简。
- 手机学习页视频使用全宽显示，课程信息和目录下移，减少横向挤压。
- 不引入 Tailwind 构建链，不增加 npm / bundler；继续使用现有 CSS，保证 WordPress 个人网站部署简单。

Commit：`6f2355bc4d852a6d9547323caa98715158d2b4a5`
