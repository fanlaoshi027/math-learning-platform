# UI Reference — wpui

这四个静态 HTML 是 `wpui` 前台 UI 的唯一视觉参考，不再以历史截图或旧 CSS 的主观设计作为基准。

## 页面对应

- `deepseek_html_20260831_f30ff0.html` → 首页
- `deepseek_html_20260831_76f2fd.html` → 课程中心
- `deepseek_html_20260831_f29112.html` → 专题详情
- `deepseek_html_20260831_e78370.html` → 学习页

## 核心视觉

- 页面背景：`#f5f7fa` / `#f9f9f9`
- Header：白色、底部 `#eee` 细线
- 主文字：`#333` / `#111`
- 辅助文字：`#666` / `#888`
- 主强调色：橙色 `#ff8c00`
- 辅助蓝：`#4a6cf7`
- 成功色：绿色
- 卡片：白色、约 8–10px 圆角、轻阴影
- 内容宽度：首页/课程中心约 1200px；学习页约 1400px
- 字体：Microsoft YaHei / 系统中文字体

## Header

静态参考采用：Logo + 首页 + 课程中心 + 学习中心 + 关于老师 + 搜索 + 登录/注册。

## 首页

Hero：深色蓝黑渐变、大标题、说明、橙色主按钮 + 白色次按钮，右侧数学图形。

Hero 下方有四项优势，再进入专题、配套课程、学习方法/思维提升、为什么选择、页脚。

## 课程中心

白色主容器，左侧约 250px 导航，右侧专题内容；课程卡片采用紧凑网格，强调专题体系而非大型营销卡片。

## 专题详情

面包屑 → 左侧视频/学习内容 → 右侧约 300px 课程目录。当前课时使用浅橙背景 + 左侧橙色边线。

## 学习页

顶部课程标题 + 学习进度；主体为左侧约 280px 课程目录、右侧视频区。当前课时浅橙高亮，完成课时显示绿色完成标记。

## 实现原则

1. 静态 HTML 决定视觉结构与样式方向。
2. WordPress/PHP 保留真实课程、权限、视频、进度等业务逻辑。
3. 不为了 UI 改动破坏 HLS、学习进度或课程授权。
4. 手机端根据静态页面的布局意图做响应式重排，而不是简单缩小桌面布局。
5. 后续 UI 修改优先使用现有主题/插件前台 CSS；只有 DOM 结构无法表达参考设计时才修改模板。
